# Clínica Vida Saudável - Landing Page

Este projeto é uma landing page estática desenvolvida para a Clínica Vida Saudável, com o objetivo de apresentar seus principais serviços, equipe e um formulário de contato. O site foi construído com HTML e CSS puro, focando em acessibilidade, clareza e uma boa experiência para o usuário.

## ✅ Funcionalidades

- Página responsiva com design limpo
- Exibição dos principais serviços da clínica
- Seção com equipe fictícia (fotos e cargos)
- Formulário de inscrição (nome, e-mail, cidade e estado)
- Estrutura com dois níveis de cabeçalhos (`<h1>` e `<h2>`)
- Botão de “voltar ao topo”

## 💻 Como usar

1. **Clone ou baixe** este repositório no seu computador.
2. Certifique-se de que as imagens estão dentro da pasta `imagens/` com os nomes corretos.
3. Abra o arquivo `index.html` em qualquer navegador moderno.
4. Pronto! A landing page será exibida localmente.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

## 📌 Observações

- O formulário é estático e não realiza envio real de dados.
- As imagens usadas são fictícias e podem ser substituídas conforme a identidade visual da clínica real.
